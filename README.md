# Expense Tracker API

A simple ASP.NET Core Web API project to manage expenses.

## Features

- Get all expenses
- Get expense by ID
- Add new expense

## Technologies

- ASP.NET Core
- C#
- Minimal DTO/Service architecture

## How to Run

1. Open in Visual Studio
2. Run the project
3. Use Swagger or Postman to test endpoints

## Project Description

This is a personal expense tracking REST API built with ASP.NET Core.
It allows users to add, retrieve, and manage expenses, using a clean architecture with DTO separation and controller-based routing.
The API is documented with Swagger and fully version-controlled with Git.

Technologies used: ASP.NET Core · C# · REST · JSON · Swagger · Git · GitHub

💡 This project was built as part of a professional portfolio to demonstrate backend development skills in .NET.
